# 资产库后端（PostgreSQL + Fastify + 本地磁盘）设计文档

> 目标：把当前“本地上传 + objectURL + 内存资产库”切换为“后端资产库 + 静态文件直出”，前端只保存 rooms/items，资产由服务端统一管理。

## 0. 现状与约束

### 0.1 当前前端现状（用于迁移对齐）

- 资产上传发生在 `src/components/panels/AssetPanel.tsx`：本地 `.glb` -> `URL.createObjectURL(file)` -> `GLTFLoader` 解析 bbox -> Zustand 内存保存。
- 放置/渲染通过 `asset.url`（objectURL 或测试静态路径）加载：`FurnitureModel`/`GhostPreview` 等直接 `useGLTF(url)`。
- IndexedDB（`home-design-v2`）仅持久化 rooms/items；assets 在 `usePersistence`/`TopActions` 保存路径中是 `assets: []`（不持久化）。

### 0.2 关键决策（已确认）

- Fastify 单体服务 + PostgreSQL + 本地磁盘存储。
- 文件分发仅走 `@fastify/static` 静态直出：API 返回 `modelUrl/thumbUrl` 完整路径；不提供重复的 `/api/assets/:id/model` 下载端点。
- 上传：multipart limits 全配（50MB、parts/files/fields 上限）、始终消费流、超限清理临时文件；不信 `mimetype`，校验 GLB header。
- 落盘：使用 `uploads/.staging/`（同一文件系统）+ 原子 `rename`。
- 数据一致性：先 INSERT DB，再 `rename` 到最终路径；`rename` 失败执行补偿（删除 DB 行/或清理 staging）。
- 缩略图：Playwright 常驻 browser，每次开 page 渲染并截图；失败允许入库，`thumb_path = NULL`，前端降级通用图标。
- 前端：assetSlice 改为 API 驱动，Asset 类型改为 `modelUrl/thumbUrl + bbox + autoScale`。

## 1. 数据模型 / PostgreSQL Schema

### 1.1 categories

- 分类用表而非 enum，便于扩展。
- `slug` 约束为小写字母/数字/连字符。
- `slug` 唯一性按 `lower(slug)` 做唯一索引，避免大小写重复。

```sql
CREATE EXTENSION IF NOT EXISTS pgcrypto;

CREATE TABLE categories (
  id   INT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  name VARCHAR(50) NOT NULL UNIQUE,
  slug VARCHAR(50) NOT NULL,
  CONSTRAINT categories_slug_format CHECK (slug ~ '^[a-z0-9-]+$')
);

CREATE UNIQUE INDEX categories_slug_unique_lower ON categories (lower(slug));

INSERT INTO categories (name, slug) VALUES
  ('沙发', 'sofa'), ('桌子', 'table'), ('椅子', 'chair'),
  ('床', 'bed'), ('灯具', 'light'), ('柜子', 'cabinet'),
  ('装饰', 'decoration'), ('其他', 'other')
ON CONFLICT DO NOTHING;
```

### 1.2 assets

- 资产主键 UUID（`gen_random_uuid()`）。
- bbox 使用 `min + size`，便于落地偏移与缩放。
- `file_path` / `thumb_path` 存相对路径（相对 `uploads/`），实际 root 可配置。
- `updated_at` 通过触发器维护。

```sql
CREATE TABLE assets (
  id           UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name         VARCHAR(200) NOT NULL,
  category_id  INT NOT NULL REFERENCES categories(id) ON DELETE RESTRICT,
  file_path    VARCHAR(500) NOT NULL UNIQUE,
  thumb_path   VARCHAR(500),
  file_size    BIGINT NOT NULL CHECK (file_size > 0),
  bbox_min_x   DOUBLE PRECISION NOT NULL,
  bbox_min_y   DOUBLE PRECISION NOT NULL,
  bbox_min_z   DOUBLE PRECISION NOT NULL,
  bbox_size_x  DOUBLE PRECISION NOT NULL CHECK (bbox_size_x > 0),
  bbox_size_y  DOUBLE PRECISION NOT NULL CHECK (bbox_size_y > 0),
  bbox_size_z  DOUBLE PRECISION NOT NULL CHECK (bbox_size_z > 0),
  auto_scale   DOUBLE PRECISION NOT NULL DEFAULT 1 CHECK (auto_scale > 0),
  created_at   TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at   TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_assets_category ON assets(category_id);

CREATE OR REPLACE FUNCTION assets_set_updated_at()
RETURNS TRIGGER AS $$
BEGIN
  NEW.updated_at = NOW();
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_assets_updated_at
  BEFORE UPDATE ON assets
  FOR EACH ROW EXECUTE FUNCTION assets_set_updated_at();
```

## 2. 文件存储结构（本地磁盘）

```text
server/
  uploads/
    .staging/
      tmp_{uuid}.glb
      tmp_{uuid}.png
    models/
      {uuid}.glb
    thumbnails/
      {uuid}.png
```

说明：

- 最终文件以 `uuid` 命名，避免文件名冲突与路径注入。
- `.staging/` 和最终目录必须在同一文件系统/挂载点，确保 `rename` 原子性。

## 3. API 设计（RESTful，前缀 /api）

### 3.1 路由

```text
GET    /api/categories
GET    /api/assets?category=sofa
GET    /api/assets/:id
POST   /api/assets
PATCH  /api/assets/:id
DELETE /api/assets/:id
```

### 3.2 Asset DTO（API 返回给前端的形状）

```ts
interface AssetDto {
  id: string
  name: string
  categorySlug: string
  modelUrl: string
  thumbUrl: string | null
  fileSize: number
  bboxMin: [number, number, number]
  bboxSize: [number, number, number]
  autoScale: number
  createdAt: string
  updatedAt: string
}
```

规则：

- `modelUrl` / `thumbUrl` 是可直接访问的静态路径，例如 `/uploads/models/{uuid}.glb`。
- 当缩略图失败时 `thumbUrl = null`。

### 3.3 参数与错误语义（最小约束）

- `GET /api/assets?category=sofa`：`category` 为 slug；不存在 slug -> 返回空列表或 404（二选一，推荐空列表）。
- `GET /api/assets/:id`：不存在 -> 404。
- `POST /api/assets`：multipart fields：`file`（glb），`name`，`categorySlug`。
  - limits 超限 -> 413。
  - GLB header 校验失败 -> 400。
- `PATCH /api/assets/:id`：允许改 `name` / `categorySlug`；不存在 -> 404。
- `DELETE /api/assets/:id`：不存在 -> 404；成功 -> 204。

## 4. 静态文件服务（@fastify/static）

- 挂载前缀：`/uploads` -> `server/uploads`（root 使用绝对路径）。
- 关键安全配置：
  - `dotfiles: 'deny'`
  - `allowedPath`：限制只允许 `models/*.glb` 与 `thumbnails/*.png`
- 缓存：UUID 文件名视作不可变，可设置长期缓存（如 `maxAge` + `immutable`）。

## 5. 上传流程（锁定版）

### 5.1 目标

- 确保 limits 与流消费正确。
- GLB 校验：magic + version + length == 实际文件大小。
- 允许缩略图失败：失败时入库但 `thumb_path = NULL`。

### 5.2 流程

1) 接收 multipart，校验 limits，写入 `uploads/.staging/tmp_{uuid}.glb`

2) 校验 GLB header

- magic：`0x46546C67`（"glTF" little-endian）
- version：必须为 `2`
- length：必须等于实际文件大小

失败：清理 staging 并返回 400。

3) 解析 `bbox_min + bbox_size + auto_scale`

4) 尝试生成缩略图 -> `uploads/.staging/tmp_{uuid}.png`

失败：记录日志，继续执行，`thumb_path = NULL`。

5) BEGIN 事务 -> INSERT assets（`thumb_path` 可为 NULL）-> COMMIT

6) `rename` GLB staging -> `uploads/models/{uuid}.glb`

失败：补偿 `DELETE FROM assets WHERE id = {uuid}` + 清理 staging。

7) 若缩略图存在：`rename` PNG staging -> `uploads/thumbnails/{uuid}.png`

失败：补偿 `UPDATE assets SET thumb_path = NULL WHERE id = {uuid}` + 清理 staging。

8) 返回完整 Asset DTO。

## 6. 缩略图生成（Playwright）

### 6.1 方案

- 服务端预启动并常驻 Playwright browser。
- 每次生成缩略图：创建新 page -> 加载最小渲染页（Three.js + GLTFLoader）-> 载入 staging GLB -> 布光/相机 -> 渲染 1 帧 -> `page.screenshot({ type: 'png' })`。

### 6.2 运行策略

- 并发：限流（建议 1-2）。
- 超时：页面级超时（例如 10-20 秒）。
- 失败降级：任何渲染/截图失败 -> 允许资产入库、`thumb_path = NULL`。

## 7. 前端迁移（assetSlice 从内存切到 API）

### 7.1 新增 API client

新增 `src/services/api.ts`，封装：

- `fetchCategories()` -> `GET /api/categories`
- `fetchAssets(category?)` -> `GET /api/assets?category=`
- `uploadAsset(file, name, categorySlug)` -> `POST /api/assets`（multipart）
- `deleteAsset(id)` -> `DELETE /api/assets/:id`
- `updateAsset(id, patch)` -> `PATCH /api/assets/:id`

### 7.2 Asset 类型调整

- 删除 `file: Blob` 与 `url: string`（objectURL）。
- 新增 `modelUrl`、`thumbUrl`、`categorySlug`、`bboxMin/bboxSize/autoScale`。

### 7.3 store / UI 调整

- `assetSlice.ts`：新增 `loadAssets`、`loadCategories`；上传/删除/更新走 API；state 保存服务端返回的 DTO。
- `AssetPanel.tsx`：
  - 上传按钮走 API（显示进度/状态）
  - 列表以 `thumbUrl` 展示缩略图；`thumbUrl=null` 显示通用图标
  - 增加分类筛选
- `FurnitureModel.tsx`：`useGLTF(asset.modelUrl)`。

### 7.4 IndexedDB 与 undo/redo

- IndexedDB 只保留 rooms/items（资产完全由后端管理）。
- undo/redo 仍只追踪 rooms/items，不受影响。
