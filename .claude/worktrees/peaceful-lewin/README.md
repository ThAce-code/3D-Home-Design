# 3D Home Design / Interior Configurator

Interactive interior layout and decoration app for room planning, furniture placement, and scene editing in the browser.

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS 4
- Zustand
- React Three Fiber
- Three.js

## Run Locally

```bash
npm install && npm run dev
```

## Features

- Build mode: drag to draw rooms and adjust wall height.
- Decorate mode: upload GLB models, click to place, then move/rotate/scale objects.
- Ctrl + click wall/roof to toggle transparency for better interior visibility.
- Automatic persistence to IndexedDB.
