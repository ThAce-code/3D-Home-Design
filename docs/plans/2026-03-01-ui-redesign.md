# UI/UX 重新设计方案

> 风格：Planner 5D 简洁直觉 + 游戏引擎深色浮动面板
> 配色：暗夜翡翠
> 更新日期：2026-03-01

---

## 一、配色规范（暗夜翡翠）

| 用途 | 色值 | 说明 |
|------|------|------|
| 背景 | `#111111` | 3D 场景底色 |
| 面板背景 | `#133D2F/85` | 墨绿毛玻璃 + backdrop-blur-xl |
| 主文字 | `#F8F5F0` | 流沙白 |
| 次文字 | `#9AB0A6` | 浅黛绿 |
| 主强调 | `#28A375` | 翡翠绿（激活/选中） |
| 次强调 | `#E1C699` | 香槟金（重要按钮/数值） |
| 危险色 | `#EF4444` | 红色（删除） |
| 边框 | `rgba(248,245,240,0.06)` | 流沙白微透明 |

通用面板样式：`bg-[#133D2F]/85 backdrop-blur-xl rounded-xl border border-[#F8F5F0]/6`

## 三、Pointer Lock 状态机（Alt 模式）

只有两种运行状态，无 ESC 退出：

```
              ┌──────────────┐
              │   页面加载    │
              └──────┬───────┘
                     ▼
            ┌────────────────┐
            │  初始未锁定     │ ← 仅首次出现
            │  LockOverlay   │
            └───────┬────────┘
                    │ 点击画布
                    ▼
            ┌────────────────┐
       ┌───►│  FPS 锁定状态   │◄───┐
       │    └───────┬────────┘    │
       │        按住 Alt      松开 Alt
       │            ▼             │
       │    ┌────────────────┐    │
       └────│  Alt 临时解锁   │────┘
            └────────────────┘
```

| 状态 | 鼠标 | 准星 | Dock | 面板 | WASD |
|------|------|------|------|------|------|
| FPS 锁定 | 隐藏 | 显示 | opacity-30 不可交互 | 收起 | 有效 |
| Alt 解锁 | 可见 | 隐藏 | opacity-100 可交互 | 可交互 | 无效 |

- LockOverlay 仅首次加载出现，点击后永久进入 FPS
- 按住 Alt 临时解锁，松开自动重新锁定
- Alt 解锁时不显示遮罩（区别于初始 LockOverlay）
- 所有 UI 元素透明度过渡 150ms

## 四、底部 Dock 栏

```
   ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐
   │ 🏠  │ │ 🪑  │ │ 🎨  │ │ 📏  │ │ 📷  │
   │房间 │ │家具 │ │材质 │ │测量 │ │导出 │
   └─────┘ └─────┘ └─────┘ └─────┘ └─────┘
```

- 位置：`fixed bottom-4 left-1/2 -translate-x-1/2`
- 背景：`bg-[#133D2F]/85 backdrop-blur-xl rounded-2xl`
- 每项：48×48 图标 + 12px 文字标签
- 间距：项间 8px，内边距 12px
- 激活：底部 2px 翡翠绿指示条 `bg-[#28A375]`，图标变亮
- 非激活：`text-[#9AB0A6]`，hover 变 `text-[#F8F5F0]`
- 点击 toggle：点击激活项弹出左侧面板，再点收起
- 快捷键：数字 1-5 对应五个 Dock 项
- FPS 锁定时：`opacity-30 pointer-events-none`
- Alt 解锁时：`opacity-100 pointer-events-auto`

## 五、左侧浮动面板

通用规范：
- 位置：`fixed left-4 bottom-24`（Dock 上方 16px）
- 宽度：256px，最大高度 `calc(100vh - 120px)`
- 背景：`bg-[#133D2F]/85 backdrop-blur-xl rounded-xl`
- 边框：`border border-[#F8F5F0]/6`
- 弹出动画：从左侧滑入 150ms translate-x
- 滚动：内容超出时内部滚动，自定义滚动条（翡翠绿细条）

## 六、右侧属性面板（选中家具时）

```
                         ┌──────────────────────┐
                         │ 双人沙发              │
                         │──────────────────────│
                         │ [移动] [旋转] [缩放]  │
                         │──────────────────────│
                         │ 位置                  │
                         │ X [====2.0====]       │
                         │ Y [====0.0====]       │
                         │ Z [====3.5====]       │
                         │──────────────────────│
                         │ 旋转                  │
                         │ Y [====90°====]       │
                         │──────────────────────│
                         │ 缩放                  │
                         │   [====1.0====]       │
                         │──────────────────────│
                         │ [🗑 删除]  [📋 复制]  │
                         └──────────────────────┘
```

- 位置：`fixed right-4 top-1/2 -translate-y-1/2`（垂直居中）
- 宽度：240px
- 背景：同左侧面板 `bg-[#133D2F]/85 backdrop-blur-xl rounded-xl`
- 弹出动画：从中心点扩散 `scale(0) → scale(1)`，`transform-origin: center`，150ms ease-out，配合 `opacity: 0 → 1`
- 取消选中 → 面板消失
- 工具栏集成在面板顶部，当前工具高亮翡翠绿
- 工具切换：Q 键轮询 translate → rotate → scale → translate...，T/R/S 直接跳转
- 删除按钮：`text-red-400`，复制按钮：`text-[#E1C699]` 香槟金
- 数值输入：滑块 + 可编辑数字，与房间面板风格一致
- FPS 锁定时：`opacity-30 pointer-events-none`
- Alt 解锁时：`opacity-100 pointer-events-auto`

## 七、右上角浮动按钮 + 准星

### 右上角按钮

```
                                    [💾] [⚙]
```

- 位置：`fixed top-4 right-4`
- 两个圆角按钮，40×40，间距 8px
- 背景：`bg-[#133D2F]/85 backdrop-blur-xl rounded-lg`
- 图标：`text-[#9AB0A6]`，hover 变 `text-[#F8F5F0]`
- 💾 保存：手动保存到 localStorage
- ⚙ 设置：弹出设置面板（快捷键一览、灵敏度调节等）
- FPS 锁定时：`opacity-30 pointer-events-none`
- Alt 解锁时：`opacity-100 pointer-events-auto`

### 十字准星（FPS 锁定时）

```
        │
     ───+───
        │
```

- 位置：屏幕正中心，`fixed top-1/2 left-1/2`
- 颜色：`text-[#F8F5F0]/60`（流沙白半透明）
- 选中资产待放置时：准星变为翡翠绿 `text-[#28A375]`
- 大小：20px 十字线，中心 2px 间隙

## 八、快捷键总览

| 按键 | 功能 |
|------|------|
| WASD | 移动 |
| 鼠标 | 环顾 |
| Shift | 加速 |
| F | 飞行模式 |
| Alt（按住） | 临时解锁，操作 UI |
| T / R / S | 切换变换工具（移动/旋转/缩放） |
| Q | 轮询切换变换工具 |
| Delete | 删除选中家具 |
| Ctrl+Z / Y | 撤销 / 重做 |
| Ctrl+D | 复制家具 |
| 右键 | 取消选中 |
| 1-5 | 快速切换 Dock 面板 |
